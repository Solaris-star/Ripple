# 参考笔记 → 原创内容

只在用户明确提供参考笔记/链接并希望“参考这种打法写我的版本”时使用。仅分析参考内容时，不自动进入创作。

## 1. 先确定可迁移与不可迁移

可迁移：Hook 类型、信息顺序、论证节奏、内容形态、封面信息角色、互动问题类型、素材组合方式。

不可直接迁移：作者个人经历、身份叙事、独特句子、专有比喻、未经授权图片/视频、品牌独有数据、无法核实的结论。

## 2. 建立原创 brief

至少写清：用户自己的主题/对象、目标受众、核心事实与证据、可用素材、想借鉴的结构特征、明确不要复制的部分。

参考内容中没有的用户事实不能靠改名补出来。缺少关键论据时先用占位/建议补充，不把参考作者的事实当用户事实。

## 3. 结构迁移

把参考内容先抽象成方法，例如：

`身份痛点 → 反常识判断 → 三个实操证据 → 使用边界 → 具体问题 CTA`

再使用用户自己的素材重新填充。不要逐句同义改写，也不要为了“相似度”维持原文句序、例子和措辞。

## 4. 视觉迁移

可以借鉴“封面承担什么信息、正文图承担什么证据、哪些页用对比/步骤”的角色分工；不要复制原图。需要精确文字时用确定性排版，插画/场景可按当前媒体模型能力生成。

## 5. 完成标准

- 新稿脱离参考原文也能成立。
- 每个事实属于用户/可靠来源，而不是参考作者私人经历的替换版。
- 能说明借鉴的是哪种结构方法，而不是“把原文换词”。
- 用户只要求局部元素（如标题）时，只处理对应范围。
