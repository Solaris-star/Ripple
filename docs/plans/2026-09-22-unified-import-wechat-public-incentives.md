# Plan: 通用活动导入与微信官方公开激励规则

状态：PLAN，待用户确认实现。本轮只读代码与公开官方资料；业务基线27f1e81，工作区开始时干净。未调用模型、未登录微信、未刷新生产活动、未重启。

## Goal / Non-goals

目标：补充导入跟随当前平台，支持活动链接、原文和手工资料，不再强制走B站；将微信官方可公开读取的创作者变现/激励规则纳入可发现来源，区分公开规则与账号资格。

非目标：不宣称已有完整微信限时活动Feed；不将商业合作、长期广告分成或官方课程当作限时比赛；不伪造奖励、期限或当前账号可参与结论。不改变默认/最新排序、每页10条、现有费用分级调度、登录隔离、发布与收藏逻辑。

## Success criteria（可验证）

1. 在公众号、视频号、小红书等平台点击补充导入，不显示固定B站URL，也不把草稿platform强制写成bilibili。手工填写继承所选平台，保留用户已贴的链接/文字。
2. B站已有解析继续正常；小红书复用既有安全的单活动详情读取。微信营销/支持文档和可访问的官方文章按专用或受限通用读法返回证据草稿。尚不支持或读取失败时保留输入，允许粘贴原文或手工补充，不静默跳回B站。
3. 预览只生成草稿，确认前不创建Campaign。默认只做免费读取/结构化解析；需要Agent时单独明确选择并标注Token消耗，不因字段缺失自动调用。
4. 来源域名和活动适用平台分离：公众号文章可介绍视频号活动，主办方网站可介绍多个平台投稿。目标平台由当前选择预填、证据核对并由用户确认，不能仅凭mp.weixin.qq.com域名确定目标是公众号。
5. 公众号流量主与视频号创作分成计划可显示公开规则、收益机制、内容条件、开通入口、原文与核验时间；不需要先连接个人账号才能显示这些公共资料。个人是否受邀、是否已开通、收益和任务进度保持待账号核验。
6. 长期计划与限时征集明确分类。分成收入不能显示为固定奖品或保证收益；无公开截止日期就保持未公布期限，不编造永久有效。手册/课程只是证据入口，不作为活动本体。
7. 公开规则来源覆盖率与账户任务来源状态独立展示；只接了若干官方文档，不得写为“微信全部活动已同步”。读取失败保留历史规则并显示状态。
8. 覆盖前后端平台继承、错误域名/本地地址/重定向安全、Token默认关闭、确认前零写入、微信两类官方样本、文章介绍其他平台、非活动文章和空正文处理。验证后提交、自动重启本地Ripple并验收新界面，用户已授权无需另问。

### 默认产品取舍

- 导入入口统一为“活动或激励计划链接”，目标平台预填当前频道并可更改；另有粘贴规则原文与手工填写路径。

## Phases / Steps

### Step 1：通用入口和解析分发

涉及CampaignsPage.tsx、api.ts、web/app.py、campaign_sources.py及相应测试。

增加target_platform、input_kind（url/text/manual）和allow_agent=false。表单保留当前平台和输入；删除draft强制B站。按受支持的URL类型分发：B站原解析器、小红书既有详情读取、微信公开规则页面读取。未知站点保留链接并提示使用原文或手工填写，不伪造解析成功。预览与创建继续分离。

网页读取仅限验证过的公共来源；检查scheme、host、端口、DNS结果、私网/本地地址、重定向每跳、响应大小和内容类型。登录态仅由对应平台隔离worker使用，绝不带到通用网址。页面内容视为数据，不能指示Agent执行任意工具。

### Step 2：微信公开规则源与分类显示

涉及campaign_sources.py、必要的小型wechat_public_rules.py、web/app.py、api.ts和CampaignsPage.tsx。

为公众号流量主、视频号创作分成保留稳定source identity、原始URL、页面标题、证据指纹、核验时间、公开条件/内容要求/收益方式/申请路径。优先脚本解析，需浏览器的文档用临时公共上下文，不要求用户登录。白名单页面只承诺当前已接入范围；导航或版本变化时显示读取异常，不能盲目接受非规则正文。

使用existing activity_type或最小扩展区分长期计划、限时活动、商业合作；长期卡片改用“收益方式/开通条件”而非比赛“奖品/获奖条件”，未公布截止日期明确显示。账户资格、是否受邀和任务进度后续经授权独立核验，不以公开规则存在就判可参与。

## Risks / rollbacks

- 公开文档会变化或依赖JavaScript：保留最后成功原文证据与版本，读取失败不删除已知记录。
- 公共规则不代表个人资格：始终分离公开来源状态与账户权益状态，避免保证收益。
- 兼容已有B站导入：保留B站特定提取器并新增回归，通用化不能降低其规则精度。
- 扩大URL入口带来SSRF和提示注入风险：受限分发与安全下载必须先于开放读取，未知站点先仅保存输入。
- 回滚仅回退本次代码与新规则源配置，不删已创建活动、用户手工编辑或收藏；新字段保持向后兼容。
